# 肌酸 Creatine — 運動表現與認知健康的雙重效益

## 基本資訊

- **名稱**：肌酸（Creatine），化學名稱為 Methylguanidine-acetic acid
- **天然來源**：肉類、魚類（約95%儲存於骨骼肌），人體亦可自行合成（肝臟、腎臟、胰臟）
- **主要形式**：肌酸單水合物（Creatine Monohydrate）是研究最充分、最廣泛使用的形式
- **人體儲存量**：約120-140g，隨體重約3.8-5.0mmol/kg肌肉
- **每日消耗**：約1-3%儲存量（約1.5-3g/day），主要經由肌酸酐（Creatinine）由尿液排出

## 作用機制

### 能量系統基礎

肌酸的核心功能在於**磷酸肌酸系統（Phosphocreatine, PCr）**：

- PCr擔當細胞內**高速能量緩衝**角色，在ATP需求驟增時迅速補充ATP
- 腦部：PCr在神經元能量代謝中扮演關鍵角色，尤其在睡眠剝奪、認知壓力下更明顯
- 肌肉：爆發力運動（10秒以內高強度）主要依賴磷酸肌酸系統

### 腦部能量代謝的分子層面

2024年 Nature Scientific Reports 研究使用磷-31磁共振光譜（31P-MRS）揭示了單次補充肌酸後的腦部代謝變化：

- **tCr/tNAA 比值上升 +4.2%**：總肌酸與N-乙醯天門冬胺酸比值增加，反映腦能量儲備改善
- **Pi/31P 下降 8.5-9.6%**：無機磷酸鹽減少，表示細胞能量狀態更佳（Pi/31P下降代表能量狀態改善）
- **PCr/31P 上升 +5.7%**：磷酸肌酸增加，直接證實肌酸補充提升了腦部高能磷酸鹽儲備
- **ATP-β/31P 下降 15-18%**：這個看似矛盾的結果反映細胞更傾向使用PCr緩衝而非消耗ATP，實際是能量效率提升的表現
- **pH穩定**：安慰劑組在睡眠剝奪後腦部pH顯著下降（-0.026至-0.032），而肌酸組成功防止了pH下降

### 認知表型

2024年 Frontiers in Nutrition 統合分析涵蓋16項隨機對照試驗、492名受試者，發現肌酸對認知功能的效果具有**領域特異性**：

- **記憶力**：標準化均數差 SMD = 0.31（95% CI: 0.18–0.44，p<0.00001）
- **注意力反應時間**：SMD = -0.31（95% CI: -0.58 至 -0.03，p=0.03）
- **資訊處理速度**：SMD = -0.51（95% CI: -1.01 至 -0.01，p=0.04）

子組分析顯示：
- 疾病族群（而非健康成人）的注意力改善更顯著（SMD -0.52，p=0.02）
- 18-60歲族群的注意力反應時間改善（SMD -0.55，p=0.002）
- 女性族群的資訊處理速度改善更顯著（SMD -0.87，p=0.01）

## 運動表現效益

### 爆發力與阻力訓練

肌酸是少數**具備強效實證支持的運動營養補充劑**，效果主要表現在：

- **力量與爆發力**：增加肌肉PCr儲備，延長10秒內高強度運動的表現
- **阻力訓練量**：可承受更多訓練量（總組數×次數），間接促進肌肉生長
- **肌肉質量**：短期內（4-12週）可增加約0.9-2.2kg去脂體重（部分為水分滯留）

### MDPI Nutrients 2025研究：7天 Loading 效果

14名活躍男性（23.9±2.3歲）隨機交叉設計，補充20g/day肌酸單水合物7天後：

| 指標 | 效應量 | p值 |
|------|--------|-----|
| 主觀睡眠質量（SSQ） | d=0.81（大效應）| p=0.009 |
| 認知表現（DCT） | d=0.77（大效應）| p=0.013 |
| 5m來回跑總距離 | r=0.88（大效應）| p<0.001 |
| 最佳來回跑距離 | r=0.76（大效應）| p<0.05 |
| 肌肉酸痛（Hooper）| d=-0.59（中效應）| p=0.046 |
| 臥床時間 | r=0.60（大效應）| p=0.026 |

這個研究的重要意義在於：7天loading除了改善睡眠質量和認知表現，同時提升了高強度間歇運動的表現（6次×30秒來回跑），且減少了運動後的肌肉酸痛。

## 睡眠剝奪與認知恢復

這是近年最具突破性的研究發現之一。Nature Scientific Reports（2024）發現：

**單次高劑量肌酸（0.35g/kg）可在21小時睡眠剝奪後顯著逆轉認知功能衰退。**

15名健康受試者（8女，年齡23±2歲）交叉設計實驗結果：

| 認知測試 | 改善幅度 | p值 |
|----------|----------|-----|
| 單詞記憶測試（WMT）| +10.3±3.8% | p=0.005 |
| WMT處理速度 | +17.7±6.0% | p=0.002 |
| 語言任務 | +29.1±5.3% | p=2.0×10⁻⁶ |
| 邏輯任務 | +16.0±4.0% | p=0.0002 |
| 數字任務 | +24.0±4.9% | p=1.02×10⁻⁵ |
| 疲勞量表（FAT）| -8±7% | p=0.002 |

這個發現的實際意義：
- 過往常見誤解是「肌酸需要數週才見效」，這個研究推翻了这个假设
- 劑量與肌肉使用的標準剂量不同（0.35g/kg，對一般成年人約21-28g）
- 對需要值夜班、長途駕駛、緊急服務人員具有實際應用價值
- 防止睡眠剝奪期間的腦能量失調和pH下降是關鍵機制

## 阿茲海默症與腦健康

2025年 Kansas 大學醫學中心啟動了首個肌酸應用於阿茲海默症患者的研究（Creatine to Augment Bioenergetics in Alzheimer's, CABA）。

**19名60-90歲阿茲海默症患者，補充20g/day肌酸單水合物8週後：**

- **安全性**：補充期間耐受性良好，無顯著不良反應
- **腦 creatine 濃度上升 11%**（使用磁共振光譜成像測量）
- **認知功能中等改善**（使用NIH Toolbox認知評估工具）

研究人員 Matthew Taylor 博士表示：「看到肌酸確實能改變阿茲海默症患者的大腦 creatine 水平，這非常令人興奮。11%的增幅是相當顯著的變化。」

### 為何需要高劑量？

一般運動員補充劑量為5g/day，但 creatine 首先要進入肌肉才會分布到腦部。研究人員使用20g/day是為了提高 creatine 到達腦部的機率。

## 老年人認知健康

Nutrition Reviews（2025）系統回顧，6項研究、1,542名55歲以上受試者：

- **83.3%的研究（5/6）**報告肌酸與老年人認知功能呈正相關
- 主要改善的認知領域：**記憶力**與**注意力**
- 研究品質：1項良好、2項中等、3項不佳
- 55.7%為女性受試者

這個系統回顧的結論是：目前證據支持肌酸可能對健康老年人認知功能有益，但需要更多高質量研究。

## 安全性評估

Frontiers in Nutrition（2025）發表了最全面的安全性回顧，評估30年以上證據：

| 安全疑慮 | 結論 | 證據等級 |
|----------|------|----------|
| 癌症風險 | 安全，甚至有潛在抗癌效果 | II |
| 腎功能（健康人）| 安全；原有腎病者需監測 | I |
| 脫水/體溫調節 | 不會損害；反而可能支持散熱 | I |
| 肌肉痙攣 | 可能減少發生率 | II |
| 腸胃不適 | 輕度、劑量依賴、不常見 | II |

**證據等級**：I = 強，II = 中等，III = 有限，IV = 專家意見

### 已知的安全使用劑量

- **標準維持劑量**：3-5g/day（終生安全）
- **Loading 階段**：20-25g/day，分4-5次服用，持續5-7天
- **研究用高劑量**：0.35g/kg（單次，約21-28g用於一般成年人）
- **阿茲海默症研究劑量**：20g/day，8週

## 實用補充方案

### 標準 Protocol（運動表現為主）

```
Loading 階段（可選）：
• 劑量：20-25g/day（分4-5次，每次約5g）
• 維持：3-5g/day
• 目的：加速肌肉PCr儲備饱和（7-10天達到穩定）
• 注意：Split doses減少腸胃不適

直接維持 Protocol（推薦懶人方案）：
• 劑量：3-5g/day
• 持之以恆，約3-4週可達到肌肉PCr饱和
```

### 睡眠剝奪/認知增效 Protocol

根據 Nature Scientific Reports（2024）單次高劑量研究：
- **劑量**：0.35g/kg體重（約21-28g）
- **時機**：睡眠剝奪前30-60分鐘
- **注意**：腎功能異常者不建議使用此劑量

### 阿茲海默症/認知老化的長期補充

根據 Kansas CABA 研究：
- **劑量**：20g/day
- **持續時間**：至少8週見初步效果
- **前提條件**：需在醫療監督下進行

## 為何重要

肌酸正從純粹的「健身補充劑」擴展為「全人健康補充劑」：

1. **價格便宜**：每月約100-200港元，CP值極高
2. **證據等級高**：是少數同時具備運動科學和人類醫學研究支持的補充劑
3. **安全性佳**：30年以上使用歷史，主要副作用輕微（腸胃不適、體重短暫增加）
4. **多效性**：同時影響運動表現、認知功能、睡眠剝奪恢復
5. **認知老化新希望**：83歲以上老年人出現認知下降時，腦能量代謝是關鍵缺口

## 批評與局限性

1. **研究品質參差**：老年人認知薈萃分析中3/6項研究品質為「不佳」，需更多高質量RCT
2. **劑量差異**：阿茲海默症研究使用20g/day是普通維持劑量的4倍，長期高劑量腦部效果數據仍不足
3. **性別差異**：女性族群的認知效果研究樣本普遍較小
4. **腦內測量方法限制**：31P-MRS 只能測量有限區域，腦 creatine 變化的空間分布尚不清楚
5. **營養狀態混雜**：部分研究未控制膳食 creatine 攝入（素食者通常肌肉 creatine 較低，可能受益更多）
